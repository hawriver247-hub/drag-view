Search Pittsboro, Siler City, Chapel Hill, or wherever you play.

How to use it

  1. Scan the code or type the link.
  2. Create an account and set a name.
  3. Search a city, then open a game on the map.
  4. Join an open table, or tap Host a game to post yours.

Keep it decent

  • Post a store, library, or neighborhood — not a home address.
  • Be clear about system, level, date, and open seats.
  • Mark the table full when it is full. Delete it when it is done.
  • Rate people you actually played with. Don’t be a jerk.
  • Bugs or problems: use the Bugs button on the site.

D&D Local is a community map for in-person games. Not affiliated with Wizards of the Coast.
